# Cloud Kitchen Website

A responsive cloud kitchen website developed using HTML, CSS and JavaScript.

## Features

- Home page
- Food menu
- Food ordering
- Shopping cart
- Checkout page
- User registration
- User profile
- Order page
- Admin dashboard
- About page
- Contact page

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` - Main landing page
- `home.html` - Home page
- `menu.html` - Food menu
- `cart.html` - Shopping cart
- `checkout.html` - Checkout page
- `register.html` - User registration
- `profile.html` - User profile
- `order.html` - Orders
- `dashboard.html` - Dashboard
- `css/` - CSS files
- `js/` - JavaScript files
- Images - Food and website images

## How to Run

Download or clone the repository and open `index.html` in a web browser.
